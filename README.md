# Peaucellier-Lipkin Linkage Simulator & Designer

ポースリエ・リプキン機構（厳正直線リンク機構）の動作シミュレーションと、引きたい直線の長さからの逆算設計ができる単一HTML製のWebアプリです。

## 主な機能 (Features)

- **リアルタイム・シミュレーション**: リンク長 ($L, s, r$) を変更しながら、円運動が厳密な直線に変換される様子をリアルタイムに描画します。
- **逆算設計モード**: 目標の直線長さ（ストローク $S$）を指定すると、条件を満たすクランク長 $r$ を自動計算します。
- **幾何学的検証**: 反転定数 $|OP| \cdot |OQ| = L^2 - s^2$ の不変性や、菱形の内角（動作の無理のなさ）・死点警告をリアルタイムに表示します。
- **SVG図面エクスポート**: 設計したリンク一式を、ピン穴付きの2Dカット用SVGデータとしてダウンロードできます。

## 使い方 (Usage)

1. リポジトリをクローンまたはダウンロードします。
2. `index.html` をブラウザで開くだけで動作します（ビルドやサーバー構築は不要です）。

## 計算式の概要 (Math)

固定支点 $O$、クランク回転中心 $O'$（距離 $r$）、長いリンク $L$、菱形の辺 $s$ を用いて、描かれる直線の位置 $d$ と最大ストローク $S$ は以下で決まります。

$$d = \frac{L^2 - s^2}{2r}, \quad S = 2\sqrt{(L+s)^2 - d^2}$$

連続した1本の直線を描くための条件： $L - s < 2r \le L + s$ （$S$ を指定した逆算時は $Ls \ge \frac{S^2}{16}$）
